# Kids Drawing App

This is a simple web application designed for children to express their creativity through drawing. The app provides an interactive canvas where users can draw, erase, and use stamps with various colors and line widths.

## Features

- **Drawing**: Users can draw on the canvas using different colors and line widths.
- **Eraser**: An eraser tool to remove unwanted drawings.
- **Stamps**: Users can place stamps on the canvas.
- **Clear Canvas**: A button to clear the entire canvas.
- **Responsive Design**: The app is designed to work on various screen sizes.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **TypeScript**: A typed superset of JavaScript that compiles to plain JavaScript.
- **Vite**: A fast build tool for modern web projects.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **PWA**: The app is configured as a Progressive Web App for offline capabilities.

## Getting Started

To run the application locally, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd kids-drawing-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to see the app in action.
